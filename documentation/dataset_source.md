
# Dataset Documentation

## Dataset Name
Iranian Customer Churn Dataset

## Original Source
UCI Machine Learning Repository

## Dataset URL
https://archive.ics.uci.edu/dataset/563/iranian+churn+dataset

## Dataset Description
This dataset contains customer information collected
from an Iranian telecommunications company over
a 12-month period.

## Dataset Size
- Customer records: 3,150
- Features: 13

## Observation Period
- First 9 months: Customer behaviour information
- Final 3 months: Designated planning gap
- Month 12: Churn outcome

## File Name
Customer Churn.csv

## Project Usage
This dataset is used for customer churn analysis,
statistical investigation, predictive modelling,
customer risk segmentation and retention
optimization.

## Important Limitation
The dataset represents an Iranian telecom company.
It is used as an international public-data case study
inspired by Sri Lankan telecommunications business
problems. It is not actual Dialog or SLT-Mobitel data.
